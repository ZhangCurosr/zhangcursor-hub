## 今日趋势观察

1. **扩散模型从"生成"向"编辑、压缩、控制"全面渗透**：本批论文中涉及扩散模型工作的占比最高，且研究重心已从单纯提升生成质量转向下游可控应用——如 MotionEditor 实现视频动作编辑（#59）、Predicated Diffusion 用谓词逻辑引导文生图（#33）、Smooth Diffusion 构建平滑潜空间以支持插值与编辑（#37）、Post-training Quantization on Diffusion Models 实现无损 8-bit 压缩（#77）。扩散模型正从"黑盒生成器"演变为可微分、可压缩、可条件控制的通用底座。

2. **3D 视觉与神经渲染呈现"多任务统一"趋势**：多篇工作围绕人体/场景的联合建模展开，不再局限于单一任务。Synergistic Global-space Camera and Human Reconstruction（#29）首次从单目视频联合恢复度量尺度相机轨迹、人体网格与密集场景点云；Score-Guided Diffusion for 3D Human Recovery（#41）用扩散 score guidance 统一处理单帧/多视图/视频三种 3D 人体恢复场景；Semantic Human Mesh Reconstruction with Textures（#42）在同一流水线中完成语义网格重建与纹理生成。此外，SfmCAD（#40）将体素形状解析为工业 CAD 操作，显示 3D 生成正与专业设计工具链融合。

3. **大语言模型推理效率优化进入"系统级深耕"阶段**：随着上下文长度竞争白热化，工作重心从算法原型转向生产部署。FlashPrefill V2（#106）将块稀疏预填充注意力升级为支持 paged KV cache 和 continuous batching 的生产系统，在 H20 上获得 47× 加速；From Retrieved Context to Runtime Control（#105）首次在边缘 SoC 上量化 RAG 系统的能耗-延迟权衡，提出运行时自适应压缩范式；Daedalus-150M（#113）专为 CPU 推理设计卷积-注意力混合架构，验证了小模型在端侧的可行性。

4. **LLM Agent 的能力边界与评估体系成为显学**：多篇论文聚焦 Agent 方法的可靠性诊断。FORMALTCS 基准（#108）首次以端到端方式评测 LLM 进行前沿形式化 TCS 研究的能力，揭示自动形式化和"研究品味"是当前瓶颈；CREDIT WITHOUT GROUND TRUTH AUDITING（#112）发现现有步骤级信用信号（Implicit/Judge）均处于机会水平；Break It Down Pass It On（#116）通过控制实验揭示子任务级与文本格式的技能迁移更可靠。这些工作共同指向一个趋势：Agent 研究正从"构建更多功能"转向"建立可信评估"。

5. **多模态大模型评估从零散基准走向系统化与结构化**：What Are We Measuring When We Evaluate Large Vision-Language（#1）对 30+ 任务上的主流 VLM 进行系统评估，通过因子分析揭示迁移性能的 6 个潜在公因子，为 VLM 评估提供了结构化视角；WaterBench（#65）首个全面评测 LLM 水印的基准，统一强度后进行联合评估；WALNUT（#26）提出首个面向 NLU 的半弱监督统一基准，揭示了弱监督方法的实际边界。

6. **跨模态对齐与生成趋向"免训练、即插即用"**：Seeing and Hearing Open-domain Visual-Audio Generation（#46）利用预训练 ImageBind 作为桥梁，在不重新训练单模态扩散模型的前提下实现视频-音频双向生成；Prompt-Driven Referring Image Segmentation（#38）通过 prompt learning 将 CLIP 与 SAM 端到端桥接；Prefix Conditioning（#85）用可学习前缀 token 统一语言和标签监督信号。这一趋势反映出社区正减少对大规模联合训练的依赖，转而探索利用已有预训练模型的跨模态对齐能力。
